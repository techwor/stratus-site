What Stratus does today

Full visibility.
Real control.

Everything you need to understand and manage cloud infrastructure across multiple accounts and clouds — without leaving your own environment.

Multi-cloud inventory

EC2 instances, RDS databases, EKS clusters, ECS services, Azure VMs, and GCP instances — all in one view across every account and region.

AWS Azure GCP

Cost visibility

Estimated monthly cost per resource, per account, and per cloud — updated on every scan. No billing API integration required.

Schedules

Automatically stop instances at night and start them in the morning. Set recurring schedules per resource with cron-style precision.

Audit log

Every start, stop, and configuration change is logged with the user, timestamp, and resource. Full compliance-ready trail.

Secure by default

TOTP two-factor authentication, role-based access (admin vs viewer), and session management baked in from day one.

Savings suggestions

Stratus flags idle resources — instances running for days with near-zero CPU — and surfaces the estimated monthly waste so you can act on it immediately.

Get started

Up in 2 minutes.

Docker Compose. No Kubernetes, no SaaS account, no credit card.

1
Clone the repo
git clone https://github.com/techwor/stratus-cloud-management.git
2
Add your AWS credentials to .env
cp backend/.env.example backend/.env
# edit AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY
3
Start
./run.sh up -d

Stratus runs on any Linux host with Docker. Open http://localhost:3001 to log in.
